# Матриця покриття навчальної програми курсу ООП

| Група тем програми | Що використано в нашому проєкті | Статус |
| :--- | :--- | :--- |
| **Основи ООП** | Класи `Vehicle`, `Car`, `Customer`, інкапсуляція станів полів через private setters. | Повністю |
| **Абстракції та інтерфейси** | Використання інтерфейсу `IRentalRepository` для відділення логіки від інфраструктури. | Повністю |
| **Generics & Колекції** | Використання `Dictionary<Guid, T>` для пошуку за O(1), впровадження узагальненого сховища `JsonDataStore<T>`. | Повністю |
| **LINQ & Делегати** | Лямбда-вирази у фільтрації даних, `Values.ToList()` та LINQ запити агрегації ціни. | Повністю |
| **Помилки & Persistence** | Обробка `IOException`, захист від Race Conditions через критичні секції (`lock`). JSON серіалізація. | Повністю |
| **SOLID принципи** | **DIP:** Сервіси залежать від абстракцій `IRentalRepository`. **SRP:** Домен відокремлений від збереження. | Повністю |
| **Тестування & UML** | Створення Unit/Integration тестів (xUnit), побудова діаграм прецедентів та класів. | Повністю |
