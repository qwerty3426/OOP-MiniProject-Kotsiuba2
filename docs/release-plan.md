# План релізу версії v1.0.0 (Release Scope)

## 1. Склад версії v1.0.0
* Повна доменна модель оренди (Car, Customer, RentalOrder).
* Потокобезпечний інфраструктурний шар з оптимізованими структурами даних (`Dictionary` замість `List` для операцій пошуку `O(1)`).
* Обробка винятків при пошкодженні даних (Fault Handling).
* Покриття автоматизованими тестами (Unit & Integration) > 80%.

## 2. Перенесено в "Після курсу" (Out of Scope)
* Побудова графічного веб-інтерфейсу (Blazor/React).
* Інтеграція з реальними платіжними шлюзами (Stripe/PayPal).

## 3. Припустимий технічний борг
* Використання файлового JSON-сховища замість повноцінної реляційної СУБД (PostgreSQL/SQL Server). Це свідомий компроміс для ітерації навчального капстоуну.
