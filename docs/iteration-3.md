# Підсумки ітерації 3. Quality Gate & Автоматизація

## 1. Метрики тестування та Покриття (Code Coverage)
* **Загальна кількість Юніт-тестів:** 20 кейсів.
* **Загальна кількість Інтеграційних/Fault тестів:** 10 кейсів.
* **Локальний статус запуску:** Успішно змонтовано, активовано збір метрик через інструмент `coverlet.msbuild`.
* **Покриття доменної логіки (Domain Layer Coverage):** > 85%.

## 2. Усунені архітектурні дефекти (Refactored Code Smells)
* **Приховані побічні ефекти (Side Effects):** Логіку роботи з файлами відокремлено від користувацького інтерфейсу консолі та винесено за інтерфейс `IRentalRepository`.
* **Жорстка залежність (Hard Dependency):** Замість прямих шляхів до файлів у коді, конструювання сховища приймає шлях динамічно, що дозволило використовувати тимчасові файли ОС (`Path.GetTempFileName()`) під час тестів.

## 3. Залишкові ризики перед релізом (Lab 37)
* **Конкурентний доступ (Concurrency):** Якщо два користувачі одночасно спробують записати дані в один JSON-файл, виникне виняток блокування процесу. У Lab 37 необхідно додати потокобезпечність (lock-механізми).
* **Політика Retry:** Наразі при помилці I/O система викидає виняток. Бажано інтегрувати бібліотеку `Polly` для автоматичного повтору спроб читання файлу.
