# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-26
### Added
- Додано потокобезпечний механізм блокування потоків (`lock`) для стабілізації одночасної роботи з файлами.
- Додано XML-коментарі до всіх публічних методів сервісів та репозиторіїв.
- Створено вичерпний набір документації (`USER_GUIDE.md`, `DEVELOPER_GUIDE.md`).

### Changed
- Оптимізовано структуру пошуку: внутрішнє сховище переведено з лінійного списку `List` на хеш-таблицю `Dictionary<Guid, Vehicle>` для прискорення пошуку до стану $O(1)$.

### Fixed
- Виправлено Race Conditions при масовому додаванні сутностей із паралельних потоків у тестових сценаріях.
