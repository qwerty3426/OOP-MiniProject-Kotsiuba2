# Сценарій демонстрації та захисту проєкту (Demo Script)

Ось чіткий 3-х хвилинний покроковий план демонстрації системи перед екзаменаційною комісією.

* **Крок 1. Демонстрація Чистого Старту (30 сек):**
  Покажіть запуск програми. Зверніть увагу, що при першому запуску, якщо файл даних відсутній, додаток не падає, а автоматично створює нову чисту базу даних в каталозі.
* **Крок 2. Успішний Сценарій "Happy Path" (1 хв):**
  Створіть у консольному меню нового користувача, оберіть автомобіль Tesla та оформіть оренду на 5 днів. Покажіть автоматичний прорахунок фінальної вартості.
* **Крок 3. Негативний сценарій & Валідація (30 сек):**
  Спробуйте ввести некоректний Email клієнта або встановити від'ємну ціну для автомобіля. Продемонструйте комісії роботу захисних доменних винятків (Fault Handling).
* **Крок 4. Збереження та відновлення стану (1 хв):**
  Вийдіть із програми через пункт меню `0`. Відкрийте створений файл JSON і покажіть збережені дані. Запустіть програму знову і продемонструйте, що всі дані успішно підтягнулися з диска.
