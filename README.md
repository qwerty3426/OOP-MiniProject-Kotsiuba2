# Система оренди автомобілів (Car Rental System)

Об'єктно-орієнтований мініпроєкт, виконаний у межах лабораторних робіт. Проєкт побудований за принципами чистішої архітектури (Clean Architecture) з чітким розділенням на Domain, Application, Infrastructure та Console шари.

---

## 🚀 Поточний статус проєкту

* **Лабораторна робота №1 (Ітерація 1):** Базова доменна модель, сутності (`Vehicle`, `Car`, `Customer`, `RentalOrder`), сервіси та ініціалізація даних. — **Завершено** ✅
* **Лабораторна робота №2 / Лаба 35 (Ітерація 2):** Впровадження патернів проєктування, кастомної обробки помилок та асинхронного збереження. — **Завершено** ✅

---

## 🛠️ Архітектурні оновлення (Ітерація 2)

У цій ітерації було реалізовано:
1. **Патерн "Стратегія" (Strategy Pattern):** Динамічний розрахунок вартості оренди через `StandardPricingStrategy` (зі знижкою від 5 днів) та `PremiumPricingStrategy` (з урахуванням страховки).
2. **Патерн "Result" (Кастомний Result<T>):** Обробка бізнес-помилок без генерації виключень (`Exceptions`), що покращує стабільність програми.
3. **АсинхроннийPersistence Layer:** Реалізовано generic-сховище `JsonDataStore<T>` для неблокуючого збереження стану системи в JSON-файли.
4. **LINQ Аналітика:** Функціонал для розрахунку загального доходу та виведення популярних брендів авто.
5. **Unit-тестування:** Проєкт повністю покритий 17 автоматичними тестами (xUnit), які перевіряють усі бізнес-правила системи.
