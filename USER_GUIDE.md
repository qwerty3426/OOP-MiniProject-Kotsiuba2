# Інструкція користувача (User Guide)

Застосунок `CarRentalSystem` є консольною системою керування автопарком та замовленнями оренди.

## Кроки для запуску системи
1. Запустіть програму через термінал з кореневої папки: `dotnet run --project src/CarRentalSystem.ConsoleUI`
2. Перед вами з'явиться головне меню системи.

## Доступні функції в меню:
* **1. Переглянути доступні авто:** Виводить повний перелік машин із зазначенням бренду, моделі та вартості за день оренди.
* **2. Зареєструвати нового клієнта:** Програма запитає ПІБ та Email. Якщо формат Email некоректний — система видасть попередження.
* **3. Створити нове замовлення:** Дозволяє обрати машину та прив'язати її до клієнта на певну кількість діб. Загальна сума прораховується автоматично.
* **0. Вихід:** Коректно зберігає всі внесені зміни у файлову базу даних JSON на диску та закриває консоль.
