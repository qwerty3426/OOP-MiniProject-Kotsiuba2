# Посібник розробника (Developer Guide)

## 1. Архітектурний дизайн
Проєкт спроєктовано за принципами Чистої Архітектури (Clean Architecture):
* **Domain:** Чисті сутності бізнес-логіки (`Car`, `Customer`, `RentalOrder`), які не мають зовнішніх залежностей.
* **Application:** Сервіси керування (`RentalService`), що реалізують сценарії використання (Use Cases).
* **Infrastructure:** Реалізація сховища даних (`RentalRepository`) та JSON серіалізація на диск.

## 2. Як розширити систему
Щоб додати нове джерело збереження даних (наприклад, базу даних SQL):
1. Створіть новий клас у шарі `Infrastructure`.
2. Реалізуйте інтерфейс `IRentalRepository`.
3. Зареєструйте нову реалізацію у файлі запуску програми `Program.cs`.
